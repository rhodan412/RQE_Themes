# Changelog

## v12.1.0.0 — Initial release (2026-10-06)

- Added **Burning Legion** as a companion theme for RQE's Quest Helper, Quest Tracker, and Magic Button.
- Added matching frame and header borders, themed icon buttons, and themed icons.
- Added three selectable background pictures: Sargeras, Fel Reaver, and Legion Warships.
- Added theme-specific card artwork for timed scenarios, Heroic, Normal, and Follower dungeons, Delves, and Torghast.
- Added Burning Legion appearance defaults and panel previews. Player selections and opacity adjustments remain in RQE's existing profiles.

**Requirement:** [RQE – Rhodan's Quest Explorer](https://github.com/rhodan412/RQE) 12.1.0.15 or newer on WoW Retail.
